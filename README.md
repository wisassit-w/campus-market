# 🎓 Smart Campus C2C Marketplace

A student-to-student marketplace web application built with **PHP** and **MySQL**.

### Key Features
* 🔐 **Auth & Shops:** User authentication, seller shop creation, and product management.
* 🛒 **Cart & Wallet:** Shopping cart flow, internal wallet balance, and transaction history.
* 💬 **Social & Admin:** Buyer-seller chat system, product reviews, and admin management panel.
* 🗄️ **Database:** Structured relational database schema (`schema.sql`).
